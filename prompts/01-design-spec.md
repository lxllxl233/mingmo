# 设计规格 · 甲申

> 本文件是 `00-master.md` 的展开。AI 在实现具体系统前应读完对应章节。
> 标注「游戏化」的地方是刻意偏离史实以服务玩法，不要当成错误修正。

---

## 1. 史观与基调

### 1.1 一句话史观

**明亡于结构，清兴于组织，顺亡于速度，南明亡于内耗。**
游戏要让玩家亲手摸到这四句话，而不是在加载界面读一遍。

### 1.2 基调

- **严肃、克制、有重量。** 参考《万历十五年》的问题意识，而不是演义小说的爽感。
- **不预设道德结论。** 明、清、顺、西、南明、郑氏都只是「在约束下做选择的人」，各有其合理性，也各有其代价。
- **暴力是后果，不是演出。** 屠城、饥荒、瘟疫以人口、民心、抵抗度、事件文本呈现，不做感官描写，不做成就奖励。
- **不确定性是诚意。** 历史人物会犯错、会病死、会投降、会反悔；AI 势力不按剧本走。

### 1.3 三条处理原则

| 情况 | 处理 |
|---|---|
| 史实明确（萨尔浒 1619、甲申 1644） | 作为**锚点**：有窗口、有前置、有强倾向，但结果可变 |
| 学界有争议（明亡主因、白银危机程度） | 做成**可选修正**：不同国策代表不同解释，各有代价 |
| 完全虚构（玩家统一天下） | 允许，但必须有**成本**与**反噬**（如：速统导致抵抗度爆表、财政崩溃） |

### 1.4 内容红线

- 不把民族矛盾写成种族优劣。
- 不把剃发、屠城、迁界做成「奖励性机制」。
- 不对历史人物做漫画化处理（崇祯不是蠢货，魏忠贤不是纯反派，吴三桂不是纯小人）。
- 所有争议性事件，事件文本必须给**至少两个立场**的叙述视角。

### 2.1 三个剧本

**剧本一 · 崇祯元年（1627-10-01）**
大明 60% 领土、财政已现赤字、辽东糜烂、党争未平、陕西未乱。
难度：中。核心体验是「在还有牌的时候做选择」。

**剧本二 · 甲申（1644-01-01）**
大顺据关中、大明据北方残局、清在关外、南明未立。
难度：高。核心体验是「三周之内决定天下」。

**剧本三 · 永历播迁（1650-01-01）**
清已据天下大半、南明据西南、郑氏据海岛、三藩未起。
难度：极高。核心体验是「以弱搏强的极限」。

## 4. 地图

### 4.1 舞台：东亚

**只做东亚。** 地图范围约东经 70°–150°、北纬 15°–55°，
从嘉峪关到日本列岛，从漠北草原到南海与缅甸。欧洲、美洲、南洋深处不画省份，
需要时以「贸易节点」抽象（马尼拉、巴达维亚、长崎）。

理由：这场易代的所有变量都在东亚内部闭合——辽东的骑兵、江南的漕粮、日本的白银、
蒙古的马市、西藏的宗教权威、缅甸的退路。把地图铺到全球，只会稀释密度。

**边缘处理：**

| 区域 | 处理 |
|---|---|
| 马尼拉、巴达维亚 | 不进地图，作为贸易节点影响 `silver_inflow` |
| 莫斯科 | 不进地图，沙俄以远东据点（雅克萨、尼布楚）出现 |
| 安南、缅甸 | 进地图（永历入缅、边境土司），非可玩势力 |
| 日本 | 进地图，分「西国 / 东国」两个地区，体现幕藩差异 |

### 4.2 三层结构

```
地区 region（30）：气候、大局战略、AI 战区划分
  └ 府 prefecture（160）：人口、阶级收入、税收、建筑、征兵、灾荒
      └ 省 province（480）：地形、行军、战斗、围城、要塞
```

- **阶级收入**、人口、粮产、建筑在**府**级结算（一个府同时有士绅、商人、农民的收入）。
- 移动、战斗、围城、补给线在**省级**结算（保留战术感）。
- UI 缩放：远看地区色块，中看府界，近看省界与地形。

## 5. 时间与节奏

- 1 tick = 1 日。四档速度：暂停 / 1x（约 4 tick/s）/ 2x / 4x。
- 月度边界：财政结算、人口增长、稳定度漂移、AI 预算。
- 季度边界：灾荒判定、贸易结算。
- 年度边界：年度事件、评分快照。
- **国策**：同一时间只能推进 1 条，耗时 60–150 日；国策点每 60 日 +1（可被修正加速）。
- **科研**：同时 2–4 槽（明 2、清 3、小势力 1–2），耗时 90–360 日。
- **税法改革**：90 日改革期 + 180 日冷却，花费 50–150 政治点；改革期内该阶级征收效率 -20%。
- **建筑**：30–200 日，占用府级建筑位。

节奏目标：
- 1627 剧本，前 3 年（约 1000 tick）必须让玩家感受到「财政在漏水」。
- 每 10–15 分钟至少一次有意义的选择（事件、国策、战和）。

## 6. 政治系统

### 6.1 五个核心数值

| 数值 | 范围 | 来源 | 效果 |
|---|---|---|---|
| 稳定度 stability | 0–100 | 事件、国策、灾荒、战败 | 低 → 税收↓、叛乱↑、事件负面 |
| 天命 mandate | 0–100 | 称帝者专属；玉玺、大捷、灾异 | 高 → 招降易、正统强；低 → 合法性危机 |
| 腐败 corruption | 0–100 | 时间漂移、党争、战争 | 税收效率↓、军饷被吞 |
| 皇权 authority | 0–100 | 国策、党争结果 | 低 → 政令不出京师、藩镇化 |
| 军心 armyLoyalty | 0–100 | 欠饷、胜败、将领 | 低 → 哗变、军阀化、倒戈 |

### 6.2 派系（宫廷政治）与阶级（经济集团）

**这是两层，不要合并。** 阶级管钱，派系管权；税法作用于阶级，国策与事件作用于派系。

| | 阶级 Estates（见 §7） | 派系 Factions |
|---|---|---|
| 本质 | 经济集团：谁占有土地、商路、粮仓 | 政治联盟：谁在朝堂上说话 |
| 核心数值 | 收入、税负、影响力、忠诚、特权 | 影响力、满意度 |
| 玩家操作 | 制定**税法**、授予/剥夺特权 | 点**国策**、回应**事件** |
| 失败表现 | 抗税、逃亡、民变、兵变 | 弹劾、政变、专权、倒戈 |
| 数量 | 8 类（势力可启用 4–8 类） | 3–8 个（势力不同） |

**派系与其支持阶级：**

| 派系 | 支持阶级 | 核心诉求 | 主要出现在 |
|---|---|---|---|
| 东林 | 士绅、官僚 | 清议、限制厂卫、保优免 | 明、南明 |
| 阉党 | 帝党、部分商人 | 皇权扩张、矿税、打压东林 | 明 |
| 帝党 | 宗室、官僚 | 强化皇权、收税 | 明、清 |
| 武将 | 军人 | 军饷、军权、招抚 | 明、南明、顺 |
| 宗室 | 宗室 | 宗禄、藩权 | 明、南明 |
| 士绅 | 士绅地主 | 优免、地方自治 | 明、南明、清 |
| 商人 | 商人 | 开海、减税、盐引 | 明、南明、郑氏、荷兰 |
| 农户 | 农民 | 减赋、赈灾 | 明、顺、南明 |
| 满洲 | 旗主、八旗兵 | 首崇满洲、圈地、旗饷 | 清 |
| 汉官 | 汉地士绅、官僚 | 科举、满汉一体 | 清 |
| 绿营 | 军人（汉） | 军饷、编制 | 清 |

规则：
- 派系影响力 ≈ 支持阶级影响力 × 系数 + 事件/国策修正；每季度重算一次。
- 满意度低于 30 → 进入负面事件池；低于 15 → 可能触发政变/倒戈条件。
- 任一派系影响力 > 55 → 触发「专权」链（东林专权 / 阉党复起 / 武将跋扈 / 满洲守旧）。
- 清不用「东林/阉党」，用「满洲 / 汉官 / 绿营」三元；蒙古、西藏、日本、朝鲜、VOC 各自 2–3 派。

### 6.3 正统与玉玺

- **传国玉玺**：1635 年前在察哈尔，之后可被清获得。持有者天命 +15、招降成功率 +10%。
- **称帝**：需要天命 ≥ 60 且控制至少一个「京师级」城市（北京/南京/西安/盛京）。
- 同时最多两个势力可自称正统；第三个会触发「正统之争」外交惩罚。

## 7. 经济、阶级与税法

> 这一章是游戏的心脏。**财政不是税率滑块，而是与八个阶级的持续谈判。**
> 玩家每调一次税，都在改变「谁替你出钱、谁开始恨你」。

### 7.1 资源与结算顺序

只有四种资源：**银（两）**、**粮（石）**、**人口**、**政治点**。

每月结算顺序（顺序不能变，否则因果链会错乱）：

```
1. 阶级收入（按府聚合，扣战乱/灾荒）
2. 征税（按各阶级税法，算逃税、抗税）
3. 支出（军饷 → 官俸 → 宗禄 → 赈灾 → 工程）
4. 欠饷累积 / 国库见底
5. 阶级忠诚漂移、影响力重算
6. 派系满意度重算（由阶级推导）
7. 抗税 / 逃亡 / 民变 / 兵变判定
8. 事件检查
```

阶级状态：

```ts
interface Estate {
  key: EstateKey;
  name: string;              // 势力内称呼，如「宗藩」「旗主」
  populationShare: number;   // 0–1
  incomeShare: number;       // 0–1，占全国阶级收入
  income: number;            // 两/年，由府级聚合
  influence: number;         // 0–100，归一化
  loyalty: number;           // 0–100
  privileges: string[];      // 特权 id
  taxLaw: string;            // 当前税法 id
  reform?: { law: string; daysLeft: number };

  custom?: boolean;          // 势力自定义阶级（如「土著」「包衣」）
}
```

**影响力（influence）**
- 高：抗税能力强、换税法成本高、能逼宫、能左右国策可用性。
- 低：任人宰割，但也没有能力闹事。
- 每季度归一化到总和 100。

**忠诚（loyalty）**
- 高：征收顺畅、事件正面、愿意借粮借钱。
- 30 以下：抗税（实收打折）。
- 15 以下：逃亡、民变、兵变、倒戈。
- 不是「好感度」：它是**合作意愿**，可以通过利益买，也可以被恐惧压。

### 7.4 税法

**每个阶级一个税法槽。** 税法决定：税率、征收效率、逃税率、货币化程度、忠诚变化、以及税负转嫁给谁。

```ts
interface TaxLaw {
  id: string;
  country?: string;          // 限定势力；空 = 通用
  estate: EstateKey;
  name: string;
  desc: string;
  rate: number;              // 名义税率 0–0.30
  efficiency: number;        // 征收效率 0–1
  evasionBase: number;       // 基础逃税率 0–0.5
  silverShare: number;       // 货币化比例 0–1，其余折粮
  loyaltyDrift: number;      // 每月忠诚漂移（相对「习惯税率」）
  influenceShift: number;    // 切换时的影响力变化
  incidence?: { estate: EstateKey; factor: number };  // 税负转嫁
  require?: Trigger;         // 解锁条件
  effects?: Effect[];        // 附加修正（如 trade_efficiency_pct）
  aiWeight: number;
}
```

**换税法 = 改革项目**，不是点一下按钮：

- 花费政治点（50–150）+ 90 日改革期。
- 改革期内：该阶级征收效率 -20%，且触发一次「阶级反应」事件（支持 / 阻挠 / 暴动）。
- 冷却 180 日；同一阶级不能连改。
- 改革失败（阶级影响力过高 + 忠诚过低）→ 政治点白花，忠诚再降。

### 7.6 结算公式

```ts
// 1. 阶级收入（月）
const income = estate.income / 12
  * (1 - province.devastation / 200)
  * famineModifier

// 2. 名义税额
const gross = income * law.rate

// 3. 逃税
const evasion = clamp(
  law.evasionBase
  + (100 - estate.loyalty) / 400
  + estate.influence / 500
  - adminCapacity / 300,
  0, 0.8)

// 4. 实收
const collected = gross
  * law.efficiency
  * (1 - evasion)
  * (1 - corruption / 200)

// 5. 入库（银 / 粮）
treasury += collected * law.silverShare
food     += collected * (1 - law.silverShare) / grainPrice
```

### 7.7 转嫁、抗税、逃亡

**转嫁（incidence）** —— 这是阶级系统的灵魂。
士绅被加税，不会自己承担，而是加租给佃农：

```
贵族/士绅税率上调 Δ
  → 目标阶级（农民）忠诚 -= Δ × factor × 200
  → 目标阶级 unrest += Δ × factor × 150
```

结果：玩家向士绅开刀，账面上多收了 50 万两，两年后西北民变。
**UI 必须把这条转嫁链显示在税法确认框里**（「预计：士绅 -12 忠诚，农民 -6 忠诚」）。

**抗税**

```
if estate.loyalty < 30:
    collected *= 0.5 + estate.loyalty / 60
if estate.loyalty < 15 and estate.influence > 40:
    每月 p = (15 - loyalty) / 100 触发「抗税」事件
```

**逃亡**

- 农民忠诚 < 15：人口以 0.5%/月流向邻府，目标府 unrest +。
- 商人忠诚 < 15：贸易量 -30%，可触发「资敌」事件（把粮铁卖给敌方）。
- 军人忠诚 < 15：整支部队忠诚下降，可能哗变或倒戈。
- 士绅忠诚 < 15：地方治安崩溃，赋税征收率断崖。

### 7.8 支出

| 支出 | 对应阶级 | 不足的后果 |
|---|---|---|
| 军饷 | 军人 | 欠饷 → 军心 → 哗变 |
| 官俸 / 养廉 | 官僚 | 腐败↑、行政能力↓ |
| 宗禄 | 宗室 | 宗室不满、藩王作乱 |
| 赈灾 | 农民 | 流民、民变 |
| 河工 | 农民、士绅 | 灾荒抗性↓ |
| 布施 / 寺院 | 宗教 | 西藏、蒙古的忠诚崩 |

### 7.9 欠饷（核心机制）

- 每月应发军饷未足额 → `arrears += 缺口`。
- 欠饷 > 3 个月军饷 → 军人阶级忠诚 -2/月；> 6 个月 → 触发哗变事件（概率随欠饷线性上升）。
- 哗变：军队忠诚骤降、可能劫掠（devastation↑）、可能倒戈（转投敌方）。
- **这是大明最真实的死法。** UI 必须在顶栏常驻显示「欠饷月数」。

### 7.10 白银与通胀

- 全局变量 `silverInflow`：受马尼拉大帆船、日本银矿、海贸政策影响，17 世纪 30 年代后下降。
- 银流入下降 → 银贵钱贱 → 农民实际税负上升（一条鞭、三饷以银计）→ 民变概率上升。
- 加派、铸钱、捐纳 → `inflation` 上升 → 粮价上升 → 城市民心下降。
- **不允许**通过「多收税」无损解决财政；加派的代价必须在一到两年内显现。

### 7.11 漕运与粮

- 南直隶 → 北京的漕运线路，每年运粮 400 万石（游戏化）。
- 线路被切断（战乱、运河淤塞、海盗）→ 京师粮价暴涨 → 稳定度骤降。
- 国策「改海运」「迁都南京」可以改变这条命脉。
- 粮是军粮与赈灾的硬约束：银可以印，粮不能。

### 7.12 硬规则（做经济时必须守住）

1. **没有零成本加税。** 任何税率上调，都必须在 6 个月内产生可观测的忠诚或影响力代价。
2. **没有永久最优税法。** 每种税法都有明确的受损阶级，且受损方有能力报复。
3. **阶级不能全满。** 忠诚总和有隐性上限（「零和民心」）：讨好一方，必有另一方受损。
4. **抗税必须可预期。** 低忠诚 + 高影响力 = 抗税；UI 要提前预警，不能突然袭击。
5. **税基会缩水。** 战争 devastation、灾荒、逃亡都会削减税基；不能只靠加税率解决问题。
6. **改革有惯性。** 90 日改革期 + 180 日冷却，禁止一日之内连改五条税法。
7. **数字必须能对上账。** 财政面板的分项之和 = 净收入，误差 > 1 两算 bug。

## 8. 灾荒、人口、瘟疫

### 8.1 小冰期曲线

1616–1683 设置一条全局 `climateAnomaly` 曲线（0–100），1640 年代前后达到峰值。
影响：灾荒频率、粮产、疫病概率、游牧南下压力。

### 8.2 灾荒

- 每季度按省判定：`p = base × climate × (1 - 水利) × 随机`
- 灾种：旱、涝、蝗、疫、震。
- 效果：粮产 -30%~-90%、流民 +、unrest +、人口 -。
- 赈灾（花银/粮）可缓解；不赈则流民转化为农民军。

### 8.3 人口

- 府级人口按月增长，受粮产、战乱、瘟疫、赋役影响。
- 人口迁移：流民从灾区向邻府流动，形成 `refugee` 状态，提升 unrest 与民变概率。
- 人口是税基、兵源、也是负担；**没有「人口越多越好」的简化**。

### 8.4 瘟疫

- 1640 年代华北鼠疫：按省概率触发，人口 -10%~-40%，军队减员。
- 防疫国策（隔离、施药）可降低损失，但需要财政与行政能力。

## 9. 军事与战斗

### 9.0 兵源与阶级

军队不是凭空招募的，**每个兵都来自某个阶级**：

| 兵源 | 出处阶级 | 特点 |
|---|---|---|
| 卫所军 | 军人（军户） | 便宜、战力低、世袭、逃亡多 |
| 募兵 | 农民（失地流民） | 战力中、要现银、欠饷即散 |
| 家丁 | 军人（将领私属） | 战力高、忠于将领而非国家 |
| 八旗 | 军人（旗人） | 战力高、人数少、补给重 |
| 土司兵 | 农民/贵族（西南） | 山地强、军纪差、需赏赐 |
| 雇佣军 | 商人（葡/荷/日） | 火器精、价格高、外交牵连 |

规则：
- **招募消耗对应阶级的人口与忠诚**：抽丁过多 → 农民忠诚↓、田地荒废。
- **欠饷首先打击募兵**，其次家丁，最后八旗（八旗有旗地兜底）。
- 阶级忠诚 < 20 时，该阶级来源的部队每月有概率逃亡或哗变。
- 「家丁私兵」兵制会提高战力、降低国家对军队的控制（军阀化）。

### 9.1 编制

```
营 battalion（约 1000 人，可 500–1500）：最小战斗单位
标 brigade（3–5 营）：地图上的移动单位
军 army（若干标）：由将领统辖
```

地图上移动的是**标**，战斗结算到**营**。

### 9.2 单位属性

| 属性 | 范围 | 说明 |
|---|---|---|
| 兵力 strength | 0–1500 | 实有人数 |
| 组织度 organization | 0–100 | 士气与纪律，归零即溃 |
| 训练 training | 0–100 | 影响伤害与组织度恢复 |
| 装备 equipment | 0–100 | 武器甲胄火药充足度 |
| 火器率 firearmRatio | 0–100% | 火力与攻城，但雨天/潮湿减益 |
| 机动 movement | 2–6 | 每日可走省数 ×10 |
| 补给消耗 supplyUse | — | 影响所在省补给压力 |

### 9.3 兵种

| 兵种 | 特点 | 克制 |
|---|---|---|
| 步兵（冷兵） | 便宜、防御高 | 被骑兵冲击 |
| 火器步兵 | 火力高、近战弱、雨天减半 | 克制密集步兵 |
| 骑兵 | 机动高、冲击强、草原补给 | 克制火器与炮兵 |
| 炮兵 | 攻城核心、野战脆弱 | 被骑兵克制 |
| 水师 | 沿海/内河，封锁与运兵 | 依赖港口 |

### 9.4 战斗结算（逐日）

```
每日：
  1. 计算有效宽度 = min(双方投入宽度, 地形宽度)
  2. 火力阶段：fire = Σ(兵力 × 火力系数 × 火器率 × 地形/天气修正)
  3. 冲击阶段：shock = Σ(兵力 × 冲击系数 × 兵种克制 × 将领修正)
  4. 伤害分配：按对方前线单位分摊，扣除组织度与兵力
  5. 组织度判定：任一一方组织度 ≤ 0 → 撤退
  6. 追击：胜方骑兵对败方造成额外伤害
```

设计要求：
- 数值结果必须**可解释**：战斗详情面板显示每一阶段的贡献。
- 同种子同指令，结果完全一致。
- 单场战斗 3–15 日结束；围城 15–120 日。

### 9.5 围城

```
城防值 = fortLevel × 100
攻方每日削减 = 攻城值 × (1 + 炮兵加成) × (1 - 守方修正)
粮尽（守方粮草 ≤ 0）→ 每日额外削减
城防 ≤ 0 → 陷落（可选择劫掠/安民，影响 devastation 与民心）
```

- 红夷大炮是**破局关键**：无炮兵时，坚城可拖 6 个月以上。
- 守方可以「出城突袭」破坏攻城器械。

### 9.6 补给

- 每省有补给上限，超限则全军组织度每日 -1。
- 补给线从己方补给源（都城/仓库）沿己方控制省份计算；被切断 → 补给中断。
- 骑兵在草原补给消耗减半；大军入川、入滇、出塞补给惩罚显著。

### 9.7 将领

- 属性：统率、攻击、防御、机动、攻城。
- 特质：骁勇、谨慎、贪腐、跋扈、忠贞、善守、善攻、水战。
- 忠诚：低忠诚将领可能拥兵自重（军阀化）或倒戈。

## 10. 外交

### 10.1 关系与条约

- `relation`：-100 ~ +100，影响贸易、结盟、招降。
- 条约类型：停战、和议、盟约、朝贡、通商、借师、联姻。
- 宣战需要 `casus belli`（cb）：领土宣称、朝贡纠纷、援助叛军、背盟。

### 10.2 朝贡体系

- 明、清拥有「宗主」身份；朝鲜、蒙古部分部族、西藏为潜在朝贡国。
- 朝贡国提供：声望、贸易、兵源（有限）、战略缓冲。
- 宗主有**保护义务**：朝贡国被攻击而不救 → 天命 -10、其他朝贡国关系 -20。

### 10.3 招抚

- 对农民军、地方军阀、南明藩镇可用「招抚」：花银 + 给官 + 给地。
- 成功条件：对方军心低、财政困窘、我方天命高。
- 失败后果：对方实力增强、我方稳定度下降。
- **剿 vs 抚** 是大明最重要的战略分叉，必须做成互斥国策分支。

### 10.4 借师助剿

- 葡萄牙炮队（明）、荷兰舰队（郑氏/清）、朝鲜兵（清）、蒙古骑兵（各方）。
- 代价：银子、贸易特权、领土租借、外交后患。

## 11. 国策设计法则

### 11.1 结构

每个主要势力 5–7 条分支，每支 8–12 个国策，总计 50–60。

```
分支范式：
  起点（1–2 个，无条件）
    → 主线（4–6 个，线性）
      → 分叉（2 条互斥路线，各 2–3 个）
        → 终点（1 个，强效果 + 历史flag）
```

### 11.2 硬规则

1. **每条国策至少一个非数值产出**：解锁单位/建筑/科技/决议/事件/宣战理由/外交选项/税法/阶级特权。
2. **互斥必须成对且有叙事理由**（剿/抚、战/和、迁都/死守、开海/海禁）。
3. **每条分支必须有一个「代价」国策**：给强力效果但扣稳定/民心/财政。
4. **不能有「必点」国策**：每个强力国策都要有竞争性选项。
5. **历史锚点国策**（如「钦定逆案」「七大恨」）必须在窗口期内可用，但不是唯一解。
6. **AI 权重**：每个国策提供 `ai_will_do`，AI 按自身处境加权；不允许 AI 全点最优解。

### 11.3 大明分支示例

| 分支 | 关键国策 | 互斥 |
|---|---|---|
| 中枢 | 钦定逆案 / 东林辅政 / 重用厂卫 / 内阁集权 | 东林 ↔ 厂卫 |
| 财政 | 加派辽饷 / 清丈田亩 / 开海通商 / 整顿盐法 / 裁撤宗禄 | 加派 ↔ 清丈 |
| 辽事 | 关宁锦防线 / 练新军 / 火器局 / 联蒙抗金 / 与清议和 | 议和 ↔ 决战 |
| 民变 | 剿寇 / 招抚 / 以寇制寇 | 剿 ↔ 抚 |
| 改革 | 一条鞭法深化 / 考成法 / 迁都南京 / 罪己诏 | 迁都 ↔ 死守 |
| 南迁 | 南京备荒 / 漕运改海运 / 江防 | — |

### 11.4 效果 DSL

见 `prompts/02-content-spec.md` 第 5 节。修饰符必须来自白名单，禁止自由文本效果。

## 12. 事件设计法则

### 12.1 类型

| 类型 | 触发 | 示例 |
|---|---|---|
| 定时事件 | 日期窗口 + 条件 | 己巳之变 |
| 条件事件 | 状态满足即触发 | 欠饷哗变 |
| 事件链 | 上一环 flag + 延迟 | 甲申、三藩 |
| 随机事件 | MTTH + 权重池 | 地方饥荒、官员贪墨 |
| 决议 | 玩家主动，有成本 | 罪己诏、加派、招抚 |

### 12.2 选项设计

每个事件 2–4 个选项，必须覆盖三种原型（可缺省其一）：

- **强硬**：见效快、伤民心/士绅/财政。
- **妥协**：代价中等、留后患（flag）。
- **拖延/回避**：暂时无损、问题累积（变量恶化）。

### 12.3 硬规则

1. 选项的代价必须**在提示中可见**（数值或明确描述），不做信息不对称的惩罚。
2. 事件链长度 3–6 环；每环至少一个分支点。
3. 每个历史事件必须有 `historical_context` 字段（一句话史实说明），供 UI 展示。
4. 不允许「无预警的纯随机灾难」；随机事件必须有前兆（灾荒指数、欠饷、民怨）。
5. 同一条事件不重复触发（除非显式 `repeatable: true` 且设冷却）。

### 12.4 甲申链（示例结构）

```
1644-01 西安称帝（大顺）
  → 1644-02 北京告急（明）
      ├ 调吴三桂入卫 → 1644-03a 山海关
      ├ 南迁 → 1644-03b 南京续命
      └ 死守 → 1644-03c 城破
  → 1644-04 清军入关（清，条件：吴三桂开关 / 明已亡）
      ├ 为崇祯复仇 → 合法性+
      └ 直接南下 → 抵抗度+
```

## 13. 科研

### 13.1 五类

| 类别 | 内容 | 代表科技 |
|---|---|---|
| 军事 | 冷兵器、火器、战术、城防、水师 | 鸟铳改良、佛郎机、红夷大炮、棱堡、车营 |
| 农业 | 作物、水利、农书、屯田 | 双季稻、番薯玉米、水利法、屯田制 |
| 行政 | 考成、保甲、驿传、文书 | 考成法、保甲制、驿传改革 |
| 财政 | 会计、盐法、关税、钱法 | 一条鞭法、盐引、海关、银钱比价 |
| 思想技艺 | 实学、西学、历法、工艺 | 阳明后学、几何原本、崇祯历书、天工开物 |

### 13.2 机制

- 研究槽 2–4；每项 90–360 日。
- 前置科技链；部分科技需要**条件**而非前置（如「有传教士」「缴获葡炮」「有徐光启」）。
- 加速：相关书籍、人才、缴获、传教士、他国交流。
- 科技不是线性变强：火器科技提升火力，但增加补给消耗与炸膛风险；骑兵科技在草原更强。

| 棱堡 | 城防 +30%，敌军攻城速度 -20% |
| 番薯玉米 | 山地/旱地粮产 +30%，灾荒抗性 + |
| 一条鞭法 | 税收效率 +15%，士绅满意度 -10 |
| 崇祯历书 | 天命 +5，事件「天象示警」负面减半 |
| 车营 | 野战对骑兵防御 +25% |
| 夹板船 | 海战 +20%，远洋补给 + |

## 14. AI

### 14.1 战略层（每 30 日）

```
1. 评估生存威胁（邻国军力、财政、稳定度）
2. 选目标：生存 / 扩张 / 统一 / 经济 / 复仇
3. 分配预算：军费 / 建设 / 科研 / 外交
4. 选国策（按 ai_will_do 加权，加战略倾向）
5. 战争决策：实力比 ≥ 阈值 且 有 cb 且 后方稳定
```

### 14.2 战役层（每 5 日）

- 前线判定：与敌接壤的省。
- 兵力集中：优先守关键省（都城、关隘、产粮区）。
- 进攻条件：局部兵力优势 ≥ 1.5 且补给可行。

### 14.3 不做的事

- 不做全图视野作弊（AI 有战争迷雾，但可以「记得」已知信息）。
- 不做完美最优解（保留 20% 随机性与性格差异）。
- 不为了「有挑战」而给 AI 隐形经济加成（难度用决策质量与初始条件表达）。

## 15. 胜利与评分

### 15.1 胜利条件（满足其一）

| 类型 | 条件 |
|---|---|
| 一统 | 控制 ≥ 80% 的府，且主要城市（北京/南京/西安/盛京/广州/成都）全控 |
| 承天受命 | 天命 ≥ 90，持有玉玺，且至少 3 个主要势力承认正统 |
| 割据 | 存活至 1683，保持独立，控制 ≥ 15 府 |
| 海权 | 控制 ≥ 6 个主要港口，贸易额第一，存活至 1683 |

### 15.2 失败

- 失去全部省份 → 灭亡。
- 大明：北京陷落且未南迁 → 触发「甲申」链，可选择续命（南明）或结束。
- 非灭亡但 1683 未达任一胜利 → 按评分结算。

### 15.3 评分维度

疆域、人口、财政、稳定、文化（科技+建筑）、存续年限、历史影响（flag 计数）。

## 19. 平衡与遥测

`pnpm sim --years 70 --seed N` 输出：

- 每年各势力：省份数、人口、银库、军队、稳定度、天命。
- 每年各势力：八阶级的忠诚、影响力、税负、实收（用来发现「某个阶级永远不被征税」这类问题）。
- 抗税、逃亡、兵变、民变的年度次数。
- 关键事件触发率（甲申、松锦、三藩、迁界）。
- 大明灭亡年份分布（10 个种子）。
- 玩家不操作时的「自然历史」走向，作为平衡基准。

目标区间：
- 大明在 1627 剧本的自然灭亡率 40–90%，中位年份 1640–1655。
- 清在 1644 剧本的自然统一率 30–60%。
- 任一势力不应在 5 年内被灭（除小势力）。
- 80% 的对局中，至少有一个阶级忠诚跌破 20（说明阶级系统真的在起作用）。

### 20.1 M7 的十二势力分批

**分批只是施工顺序，v1 一次性交付 12 方（见 `docs/decisions.md` D3）。**
一次做一个是不可能的，按「地形与文化相近」分四批，每批 3 个，每批都要能单独跑 70 年：

| 批次 | 势力 | 共同系统 | 验收 |
|---|---|---|---|
| 批一 | 明、清、南明 | 中原王朝：科举、党争、宗禄、漕运 | 三方互打 70 年不崩 |

- 该势力 40+ 国策、30+ 事件、一套完整阶级配置、一套独特机制、一条胜利路径。
- 用该势力开局，AI 托管 70 年不崩，玩家手动 10 年仍有选择。
