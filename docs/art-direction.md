# 美术方向 v1

目标：一眼能看出是「明末清初的纸本木刻/水墨」，而不是通用深色大战略 UI。

## 1. 画风关键词

- 纸本：米黄纸、纤维纹、轻微霉斑，不用纯白。
- 木刻：粗黑轮廓、排线阴影、套色偏移，不用高光渐变。
- 水墨：远山、云雾、留白；红色只作印/旗/警示。
- 版式：竖排标题可作点缀，正文仍横排；边框用双线或断线，不用圆角卡片堆叠。

## 2. 色板

| 变量 | 色值 | 用途 |
|---|---|---|
| `--paper` | `#f2ead8` | 主纸色 |
| `--paper-deep` | `#e6dcc6` | 顶栏/底栏/次级纸 |
| `--ink` | `#1f1c18` | 主文字/木刻轮廓 |
| `--ink-soft` | `#5c5244` | 次级文字 |
| `--red` | `#9e2b25` | 印、危险、主按钮 |
| `--gold` | `#b8892e` | 强调、选中、边框 |
| `--green` | `#3f6b3a` | 正向、完成 |
| `--blue` | `#2b4a6f` | 水系、海贸 |

势力色只用于地图、旗帜、小色块；不要大面积铺满 UI。

## 3. 字体

- 标题/正文：`Noto Serif SC` / `Source Han Serif SC` / `Songti SC` / `SimSun`。
- 数字、日期、资源：衬线数字即可，不引入等宽字体。
- 字距：标题 `0.08em`–`0.12em`；正文默认。
- 不使用的：圆体、无衬线主标题、手写体大段正文。

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| 面板标题 | 左侧 4px 朱红竖条 + 双线/下划线；不加大圆角 |
| 按钮 | 1px 墨线、3px 圆角；主按钮朱红底纸色字；危险按钮红字 |
| 选项卡 | 选中：朱红左条 + 淡红纸底；不选：透明 |
| 事件弹窗 | 左图右文；插图 190px 木刻 SVG；选项前加金色菱形 |
| 领袖肖像 | SVG 木刻排线、双线框、朱印；不用照片/Q 版大头 |
| 地图 | 纸底、墨线边界、低饱和势力色；海面留白，不加蓝色渐变 |
| 图表 | 细墨线、朱红数据点；不用 3D/阴影饼图 |

## 5. 资产清单

- `ui/overlays/EventArt.tsx`：六母题事件插图（战/灾/朝/海/商/变）。
- `ui/panels/LeaderPortrait.tsx`：程序化木刻领袖肖像。
- `public/audio/music/original/*.wav`：原创程序化配乐（CC0）。
- `public/audio/music/api/*.mp3`：CC BY 3.0 曲目，署名在 `CREDITS.md`。
- `public/audio/voices/*.mp3`：短语音；失败时只保留鼓点，不回退 TTS。

## 6. 验收

- 1280×800 / 1440×900 / 1920×1080 截图均无溢出、无纯白大块。
- 事件弹窗截图可直接作宣传图。
- 音频：无机器人 TTS；音乐/音效可分别调音量；所有第三方音频有署名。
- 新增 UI 必须复用现有色板与组件，不引入第二套视觉语言。
