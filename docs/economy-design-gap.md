## 2. 当前经济系统实际运作方式（现状，非理想）

一个月的结算顺序（[economy.ts:156](src/engine/systems/economy.ts#L156) 起）：

1. **经济大盘**：逐省累加 `田亩×地价 + 人口×人均产出`，乘以核心省系数（coreFactor）、战损系数，再乘稳定系数得到「pie」。
2. **分配归一化**：每个阶级有一个「最低分配份额」= `min(45, 2 + 影响力×0.13)`；玩家实际分配值不得低于该下限；若总和超过 100% 则按比例缩放。
3. **征税**：每个阶级的 `分配份额 × pie × 税率 × 效率 × (1-逃税)`，逃税由忠诚度、影响力、行政能力决定；商人阶级额外乘「贸易效率」。税分银/粮两种入库（按 `silverShare` 折算）。
4. **扣除顺序**：税收 → 腐败侵蚀（`总税 × 腐败值/135`）→ 忠诚维稳成本（`总税 × (1-平均忠诚/100) × 0.42`）→ 结构压力（若有）→ 购粮支出 → 军饷 → 库藏火耗（囤银超过上限按月烧）。
5. **欠饷/债务**：结算后国库若为负，缺口计入 `arrears`（总债务），其中军饷部分额外计入 `wageArrears`（欠饷）；盈余时优先足额补发欠饷。
6. **忠诚度漂移**：每阶级忠诚变化 = `(分配份额 - 人口份额)×3` + `(惯例税率-现行税率)×敏感度×4` + `税法忠诚漂移×0.3`。
7. **稳定度与天命**：稳定度向「影响力加权的平均忠诚」靠拢；天命变化 = 忠诚项 + 稳定项 − 腐败项。
8. **危机**：财政危机/粮荒危机各自累积天数，触发军队组织度下降、减员、稳定/天命下降，最终国家崩溃分家（[crisis.ts](src/engine/systems/crisis.ts)）。

军队相关（与设计强相关的部分）：

- 训练：入队后**每日**扣 60% 钱粮，扣不足则停滞；完成自动在兵营省生成军队（[training.ts:123](src/engine/systems/training.ts#L123)）。
- 军饷：每月按兵力×兵种系数×通胀×修正结算（[economy.ts:83](src/engine/systems/economy.ts#L83)）。
- 战力惩罚：欠饷约 5 个月军饷后战力趋近 −80%；其他债务最多 −10%（[crisis.ts:30](src/engine/systems/crisis.ts#L30)）。

## 3. 设计逐条对照

图例：✅ 基本符合 / 🟡 部分符合（有偏差，需讨论） / ❌ 不符合（当前没有或机制不同）。

### 3.1 国家机器属性

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 天命（合法性） | `mandate`，0–100 | ✅ |
| 稳定度 | `stability`，0–100 | ✅ |
| 人口 | 按省 `population`，聚合 | ✅（非单一国家值） |
| 银 | `treasury` | ✅ |
| 粮 | `food` | ✅ |

现状额外多出：人力 `manpower`、政治点 `politicalPower`、腐败 `corruption`、权威 `authority`、军心 `armyLoyalty`、通胀 `inflation`、厌战 `warExhaustion`、经济动能 `economicMomentum`。这些是超出你设计清单的扩展，不是冲突。

### 3.2 阶级划分

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 统治阶级、商人、地主、小生产者、农民（5 类） | dynasty 宗室 / nobles 贵族 / officials 官僚 / gentry 士绅(≈地主) / merchants 商人 / peasants 农民 / soldiers 军人 / clergy 宗教（8 类，各国不同） | ❌ 分类体系不同 |

要点：
- 你的「统治阶级」在现状里被拆成 **宗室 + 贵族 + 官僚** 三个阶级，各自有独立影响力/忠诚/税法。
- 「地主」≈ `gentry`（士绅）。
- 「小生产者」**没有对应**——现状没有手工业者/小生产者阶级，最接近的是 `peasants`（农民）或 `merchants`（商人），但语义不同。
- 现状额外有 `soldiers`（军人）和 `clergy`（宗教）两个阶级，且在多个国家是核心势力（八旗兵、喇嘛等）。

这是讨论优化时最需要先对齐的分歧点：**是保留 8 阶级的细粒度，还是回归你设计的 5 阶级抽象。**

### 3.3 经济大盘与分配

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 全国人口与田地先形成经济大盘 | `pie = Σ(田亩×地价 + 人口×人均) × 稳定系数` | ✅ |
| 大盘按百分比分配给各阶级 | 分配份额决定每阶级的计税基数 | ✅ |
| 各阶级有最小分配百分比 | `min(45, 2 + 影响力×0.13)` | ✅ |
| **大盘产出银的数量和贸易效率有关** | 贸易效率只作用于「商人阶级的征税效率」和郑氏海贸收入，**不直接放大整块大盘** | 🟡 偏差 |

贸易效率的作用范围比你说的窄：它不改变「人口+田地」形成的总盘，只改变商人那一块的征收效率。若你希望贸易效率整体抬高经济大盘，当前没有这条链路。

### 3.4 阶级属性：影响力 / 忠诚 / 贪腐 / 维稳

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 每阶级有影响力 | `influence`，0–100，随税改/事件/特权变动 | ✅ |
| 每阶级有忠诚度（最大 100） | `loyalty`，0–100 | ✅ |
| **统治阶级、商人、地主会贪腐，有贪腐值** | 腐败是**国家层面单一标量** `corruption`，非按阶级；且只有「官僚忠诚<30」和「囤银超限」会推高腐败漂移，商人和地主本身没有独立贪腐值 | ❌ |
| **小生产者、农民需要维稳** | 维稳成本 `忠诚维稳 = 总税×(1-平均忠诚/100)×0.42`，用的是**所有阶级的平均忠诚**，不专门区分农民/小生产者 | 🟡 偏差 |
| 影响力×分配决定该阶级对稳定度的影响 | 稳定度目标 = 「影响力加权的平均忠诚」，影响力越高的阶级忠诚对稳定度拉动越强 | ✅（但媒介是「影响力×忠诚」而非「影响力×分配」） |

贪腐模型是第二大分歧：你的设计是「每阶级一个贪腐值，贪腐×影响力」，现状是「单一国家贪腐值，对总税一刀切」。同时现状的「维稳」其实更接近「低忠诚惩罚」，不是针对农民/小生产者的专门维稳费用。

### 3.5 分配 → 忠诚 → 天命 的因果链

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 分配可以提升或减少阶级忠诚度 | 忠诚漂移 = `(分配份额−人口份额)×3` + 税率压力项 + 税法漂移 | ✅（基准点是「人口份额」而非固定基线） |
| 忠诚度决定天命 | 天命变化 = `(平均忠诚−50)/600 + (稳定度−50)/1000 − 腐败/1200` | 🟡 部分：忠诚**间接**影响天命，且权重弱于稳定度；天命更多由稳定度驱动 |

### 3.6 收入：税收 → 贪腐 → 维稳 → 最终收入

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 分配后根据税收政策获得收入 | 每阶级按份额×税率×效率征税 | ✅ |
| 收入先扣贪腐、再扣维稳费用 | `腐败侵蚀` + `忠诚维稳` 均从总税扣除 | ✅（顺序一致） |
| **贪腐值 × 阶级影响力 计算贪腐** | `腐败侵蚀 = 总税 × 腐败值/135`，**没有乘阶级影响力** | ❌ |

### 3.7 军队：训练、部署、军饷

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 先训练，训练完自动部署 | 入队训练，完成自动在兵营省生成军队 | ✅ |
| 训练期间持续扣训练费用 | **每日**扣 60% 钱粮，不足则停滞 | ✅ |
| 部署后每月扣军饷 | 每月按兵力结算军饷 | ✅ |

### 3.8 债务：欠饷 vs 事件债务

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 债务分「欠饷（部署+训练）」和「事件债务」两部分 | 区分了 `wageArrears`（欠饷）与 `arrears`（总债务），事件债务通过 `addTreasury` 负值效果进入，最终并入 `arrears` | 🟡 部分 |

现状确实把「欠饷」单独记账，但「事件带来的债务」**没有独立桶**——事件只是直接扣国库，扣成负就变成 `arrears`。欠饷（部署+训练期间的费用）也没有单独从 `wageArrears` 里区分「训练欠费」与「军饷欠费」，训练费用是每日直接扣国库/粮，不是按月入账。

### 3.9 当月结余与债务清偿顺序

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 最终收入 → 扣训练和军饷 → 扣购粮 → 扣债务 = 当月结余 | 结算链：税 → 腐败/维稳 → 购粮 → 军饷 → 火耗；训练费**不在月度结算里**（每日单独扣）；债务补发在结算后、从国库余额里扣 | 🟡 偏差 |

主要偏差：
- **训练费用不在月度结算序列中**，是每日硬扣，你想要的「最终收入先扣训练」没有实现为月度账目。
- 债务清偿（补发欠饷）发生在结算之后、作用于国库余额，而不是「扣减当月净收入」的一环——两者结果接近但账面上不一样。

### 3.10 债务 → 军队战斗力的惩罚

| 你的设计 | 现状 | 结论 |
|---|---|---|
| 欠饷逐渐让军队失去战斗力 | 欠饷约 5 个月军饷后战力趋近 −80%，拖越久越重 | ✅ |
| 非欠饷债务让军队减约 10% 战力 | 其他债务最多 −10%（约 100 万两时封顶） | ✅ |

## 4. 关键差异总结（可直接拿去问 GPT）

按「值得讨论/影响最大」排序：

1. **阶级粒度**：设计 5 阶级 vs 现状 8 阶级（且拆分了「统治阶级」为宗室/贵族/官僚，新增军人、宗教，缺「小生产者」）。→ 是保留细粒度还是收敛到你 5 阶级？这会牵动所有税法/特权/事件数据。

2. **贪腐模型**：设计「每阶级贪腐值 × 影响力」vs 现状「国家单一贪腐值，一刀切扣总税」。→ 是否值得按阶级建模贪腐？复杂度/收益权衡。

3. **维稳成本**：设计「针对农民/小生产者按忠诚度算维稳」vs 现状「全阶级平均忠诚的统一低忠诚惩罚」。→ 是否要把维稳从「惩罚」改造成「主动的维稳预算」？

4. **贸易效率的作用范围**：设计「贸易效率决定经济大盘产银」vs 现状「只放大商人阶级税收，不动大盘」。→ 要不要加一条「贸易效率 → 大盘」的链路？

5. **小生产者阶级缺失**：现状没有手工业/小生产者，是否要加？加在哪里（城市发展？商业？）。

6. **债务记账粒度**：现状区分了欠饷 vs 其他债务，但没有独立「事件债务」桶，训练欠费也未单独记账。→ 是否要三桶（欠饷/训练欠费/事件债务）或维持两桶。

7. **训练费用与月度结算的关系**：设计把训练费纳入月度结余，现状是每日硬扣、不进月度账。→ 是否统一口径，方便玩家对账。

## 5. 已符合你设计、不必改的部分（避免 GPT 重复建议）

- 国家机器五属性（天命/稳定/人口/银/粮）都在。
- 经济大盘 = 人口 + 田地，按百分比分配，有最低分配下限。
- 分配 → 忠诚、影响力 → 稳定度、忠诚 → 天命的因果链成立。
- 税收 → 贪腐 → 维稳 的扣除顺序正确。
- 训练→自动部署→军饷 的军队经济闭环完整。
- 欠饷重创战力、其他债务 −10% 的惩罚已实现。
