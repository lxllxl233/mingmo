# 明末 华夏震荡 · 怎么玩 / 怎么验

> 单机、浏览器运行、省份—地区级日 tick 大战略。舞台限定东亚，1616–1683。
> 可玩势力按剧本存在：1627/1644 各 11 方，1650 为 10 方；南明只在 1650 存在，1627/1644 不再提前出现。

---

## 1. 启动

```bash
pnpm install
pnpm dev
```

打开终端提示的 `http://127.0.0.1:5173`。

首次进入是剧本 / 势力选择：

- **1627 崇祯元年**：大明仍有牌可打，但财政已在漏水。
- **1644 甲申**：三周之内决定天下。
- **1650 永历播迁**：清已据大半，南明与郑氏以弱搏强。

选择势力与随机种子后点“开始游戏”。同一种子 + 同一串操作会得到逐日一致的结果。

> 如果终端没有 `pnpm`，用 DSH 内置 pnpm：
> `node "C:\Users\<你>\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" "...\pnpm\bin\pnpm.mjs" dev`

## 2. 界面

```
顶栏：日期 / 势力 / 银 / 粮 / 兵源 / 稳定 / 天命 / 欠饷 / 存档
左栏：国策 科研 阶级 财政 军事 外交 决议 日志
中间：地图（滚轮缩放，拖拽平移，点击省份）
右栏：选中省份 / 当前面板
底栏：暂停 1x 2x 4x / 当前国策 / 消息
```

- **地图**：画布铺满地图区域并随窗口缩放；海岸线与周边陆块来自地图册数据（world-atlas），省界再按 480 省裁切；省份按控制者着色，叠加地形符号（山地/丘陵/荒漠/水网/草原/丛林/平原）；国名按疆域大小缩放，小势力名称默认隐藏，放大后才显示；周边不可进入地区以**近白色块**表示，只标地理名称（中亚、南亚、南洋），海域标注渤海、黄海、东海、南海、日本海等。
- **地图模式**：点击左侧“阶级 / 财政 / 军事 / 外交”会切换到对应地图模式：阶级按占优阶级着色、财政按发展度着色、军事按我军/敌军/无军着色、外交按交战/友好/中立着色；地图左下角显示图例。
- **缩放**：滚轮每格约 35% 放大幅度，最大可放大到台湾约占半个屏幕；深度放大时国名、兵模和边界线宽会自动保持屏幕尺寸。
- **旗帜与兵牌**：势力档案标题显示旗帜；地图兵模右上角显示势力简称（明 / 清 / 顺 / 西 / 南 / 郑 / 蒙 / 朝 / 日 / 藏 / 荷 / 俄 / 藩）。
- **右键地图**：没有选中军团时，打开该省控制者的**势力档案**；已选中军团时，右键目标省份会让该军团自动寻路行军；按住 `Ctrl` 右键可以连续追加行军节点。
- **开局选择**：第一步只展示剧本与史实背景；进入第二步后选择势力，势力卡显示旗帜、领导人、前因、目标与历史结局。
- **训练与行军时间**：2 营训练约 120 日；平原行军约 4 日/地区，山地、水网与炮兵会显著变慢。
- **军队维持**：军队每月消耗银两与口粮，顶栏悬浮窗会列出军饷、官俸、宗禄、军队口粮、民用口粮和训练日耗。
- **侧栏国家徽记**：左栏顶部显示本国旗帜、国名与领导人头像，点击直接打开当前国家详情。
- **战争与议和**：外交面板显示每场战争的战争分、占领/失守省份，以及双方**伤亡**与**投降倾向**；可选择**白和**（归还占领）、**按现状议和**（按占领割让）或**强制议和**（领先时额外索取赔款）。宣战时可选择边境争端、收复失地、藩属争夺、统一天下等战争目标。议和后 365 日停战，停战期内不能再次宣战。
- **藩属与上供**：朝鲜、藩属（中南半岛）在剧本中作为藩属国存在。宗主国每年可要求一次上供，金额为藩属当前国库白银的 20%；藩属可能拒贡，拒贡会立即脱离藩属关系并爆发战争。藩属势力整体已削弱。
- **地形与行军**：平原、丘陵、山地、水网、荒漠、草原、丛林有不同移动成本；骑兵在平原/草原/荒漠更快，炮兵在山地/丘陵/水网更慢，科技与“辎重营”会提高行军速度。
- **全军的行军轨迹**：所有本国军团的行军路线都会显示；选中军团为金色高亮，其余军团以本国色细线显示。
- **地图标签层级**：缩小时显示国名；中等缩放显示省份名；深度放大后显示“荆州”“荆州东”“荆州西”等具体地名，并保留省界线。
- **军队通行**：军队只能进入本国控制的省份，或与自己处于战争状态的国家省份；中立国不自动给予通行权。
- **兵模堆叠**：同一省份同一势力的军团合并为一个兵模，显示总兵力与“×N”堆叠数；点击可在堆叠内轮换选择。兵模尺寸不再随缩放变小。
- **音乐**：开始页与游戏内有程序化音乐；顶栏 `♫` 可打开播放列表，选择曲目、列表循环、单曲循环、关闭音乐，并可拖动音量滑杆。
- **难度**：开局第二步可选择简单 / 普通 / 困难；难度只改变 AI 的宣战时机、目标选择与出兵规模，不给 AI 任何资源或战斗数值加成。
- **国策线路**：国策面板顶部显示路线节点与互斥线路；互斥卡会标出红色边框、对应节点和具体互斥对象。每项国策卡都有示意图。
- **被宣战**：玩家被宣战时，游戏会暂停并弹出战报，可查看敌国后选择迎战。
- **训练部署**：选择模板后，可部署的我方地区（水军为港口）会以绿色高亮；训练完成后成军。
- **外交地图模式**：打开某国档案时，地图按**该国**的对外关系着色：交战红色、友好蓝色、中立灰色、该国金色；档案内列出该国与所有存活势力的关系，并另列“对我国”的关系。
- **行军轨迹**：选中本国军团后，地图显示金色计划路线、箭头与途经节点；已经走过的路线以淡色轨迹保留。
- **军队操作**：只有本国军团可选中、可移动；点击军团打开**军团详情**而不是军事列表；左键其他省份会取消军团选择并打开省份面板；军详情里可更换将领，将领有头像，通用/随机将领使用统一头像。
- **军事总览**：军事面板显示陆军支数、水军支数、总兵力与训练中数量。
- **训练队列**：招募不再瞬间成军；新兵进入训练队列，按编制规模训练数十日。训练期间每日扣除**完成后总钱粮的 60%**；钱粮不足时训练停滞。完成时军团出现在训练省份。训练弹窗按“本国军种 / 他国军种”分组，并显示兵种图标；他国军种同时最多训练 2 支。
- **开局军队**：1627/1644/1650 三个剧本按势力重新配置了更多军团与分布，包含京营、关宁、宣大、陕西、南京、水师、八旗、绿营、顺军、西营、郑氏水师、蒙古骑兵、朝鲜军、日本武士/水军、藏兵、公司卫队与哥萨克等。
- **港口与海运**：沿海港口标有锚点；在港口可建造战船；陆军在港口且有本国舰队时，可在军团详情选择目标港口“登船海运”，3 日后抵达。港口省份即使与本土切断也视为有补给。
- **补给**：军团能从本土经友好省份连到首都，或位于本国港口，即正常补给；被切断的内陆军团会消耗补给并降低组织度。
- **将领特质**：史实将领拥有善守/骁勇/谨慎/攻城/水战等特质，分别影响攻击、防御、围城、行军与组织恢复；军团详情会列出特质效果。
- **领导人特质**：史实领导人有国家修正（税收、稳定、腐败、军队等）；势力档案可展开“生平时间线”。
- **顶栏悬浮窗**：鼠标移到银、粮、兵源、稳定、天命、欠饷上，会显示本月收支、欠饷月数、兵力、稳定风险等详情。
- **开局态势**：开始界面选择势力后会按实际初始状态显示国库、粮储、兵源、稳定、天命、控制省份、军团和战争数。
- **军队堆叠**：同省多支军团按环形/网格错开，跨省相邻军团也会自动避让。
- **国策**：6 条分支 × 7 层，共 42 条/势力；前置、互斥、耗时、完成效果。
- **科研**：5 类 60 项；研究槽有限，前置与条件科技会灰显。
- **阶级**：8 个阶级卡片；每阶级一个税法槽，可改税，但需要 90 日改革 + 50 政治点，期间征收效率 -20%。
- **财政**：本月收入按阶级拆开，支出按军饷 / 官俸 / 宗禄拆开，附 24 个月趋势。
- **军事**：军团列表、征募、选中军团后点地图省份“行军到选中省份”。
- **外交**：关系矩阵、战争列表、宣战 / 议和。
- **决议**：主动施政，有成本、冷却、可用条件。
- **日志**：财政、军事、外交、阶级、灾荒、宫廷事件按时间倒序。
- **音效**：顶栏 `♪` 开关；点击、命令、事件、战斗、存读档都有程序化音效（无外部音频文件）。


### 操作要点

1. 开局先看**财政**：大明默认税法下通常已经是月净赤字。
2. 点**阶级**改税：向士绅 / 商人开刀能立刻增收，但会通过 `incidence` 转嫁给农民，并在 1–2 年内变成民变。
3. 点**国策**：先点能解锁税法 / 特权 / 决议的路线，不要只看数值。
4. 事件弹窗会暂停时间；每个选项都有可见代价。选完点 1x/2x/4x 继续。
5. 欠饷 > 3 个月，军心开始掉；> 6 个月容易哗变。顶栏欠饷常驻显示。
6. 存档 / 读档在顶栏；每年 1 月 1 日自动存档一次。

## 3. 核心机制

### 3.1 时间

1 tick = 1 日；1616-01-01 至 1683-12-31 共 **24,837** 日。

- 月度：阶级收入、征税、支出、欠饷、忠诚漂移、AI 决策、事件。
- 季度：阶级影响力归一化。
- 年度：终局判定 / 自动存档。

### 3.2 阶级与税法

八个固定阶级：`dynasty` 宗室、`nobles` 贵族、`officials` 官僚、`gentry` 士绅、`merchants` 商人、`peasants` 农民、`soldiers` 军人、`clergy` 宗教。势力按史实启用 4–8 类；荷兰另有 `custom:natives` 土著。

每月结算：

```
各府收入 → 阶级收入 → 名义税 → 逃税 → 实收
  → 入银 / 入粮 → 支出 → 欠饷 → 忠诚 / 影响力 → 抗税 / 民变
```

- 税率、效率、逃税率、货币化比例、忠诚漂移、转嫁目标都在 `src/content/data/tax_laws/*.yaml`。
- 换税法不是按钮，是**改革**：90 日 + 50 政治点 + 180 日冷却。
- 士绅 / 贵族加税会转嫁给农民：`incidence` 只允许一跳。
- 抗税：忠诚 < 30 实收打折；< 15 进入事件池。

### 3.3 国策

- 同时只能推进 1 条；耗时 60–120 日（随层级）。
- 分支：中枢 / 财政 / 辽事 / 民变 / 改革 / 南迁（明）；其他势力各有 6 条。
- 互斥对：东林 ↔ 厂卫、清丈 ↔ 加派、议和 ↔ 决战、剿 ↔ 抚、迁都 ↔ 死守 等。
- 完成效果包含数值、修正、flag、决议解锁；每条第 7 层解锁一条决议。

### 3.4 事件

- **定时 / 条件事件**：日期窗口 + 状态。
- **MTTH 随机事件**：平均触发天数，按日掷骰。
- **事件链**：甲申、入关、东征、取台、丙子、锁国、固始汗、热兰遮、雅克萨 等 12 条，每条 3 环。
- **阶级事件**：`scope: estate`，按忠诚 / 影响力进池。
- 事件会暂停时间；选项效果在弹窗里可见。

### 3.5 军事

- 军团按省移动，逐日结算战斗 / 围城 / 补给。
- 战斗：火力 + 冲击，组织度归零撤退；无路可退则全军覆没。
- 围城：城防 = `fortLevel × 100`；无炮兵约 100 日破一座 8 级城，有炮兵更快。
- 补给：友方省恢复，敌方省衰减；断粮掉组织度。
- 将领：攻 / 防 / 机动 / 攻城 / 忠诚，提供战斗加成；低忠诚可后补哗变。

### 3.6 胜利 / 失败

- **一统**：控制 ≥ 384 省且六大城市全控。
- **承天受命**：天命 ≥ 90 且控制北京、南京。
- **割据**：1683 年仍存活且 ≥ 15 省。
- **海权**：1683 年控制 ≥ 6 个主要港口。
- 失去全部省份 → 灭亡；大明还会因民变 / 欠饷 / 失京师而结构性地崩。

## 4. 验证

```bash
pnpm typecheck     # 零错误
pnpm test          # 32 个测试：地图、内容、经济、事件链、国策、科研、确定性
pnpm validate      # 内容 schema + 引用 + 地图一致性
pnpm build         # 生产构建
pnpm sim --years 70 --seed 42 --scenario 1627 --player MING
```

`pnpm sim` 输出：

- `out/sim-<剧本>-<势力>-<种子>.csv`：逐年各省份数、人口、银、粮、稳定、天命、腐败、军心、欠饷、军队、战争、月净额。

70 年 × 24,837 tick 在本机约 45 秒，平均 ~1.8 ms/tick；月度峰值会更高。

## 6. 加内容

### 加一条国策

编辑 `src/content/data/focus_packs.yaml`，在对应势力的分支里加一行：

```yaml
- { id: ming_fiscal_new, name: 新税法, tier: 6 }
```

然后 `pnpm validate`。效果由 `kind` + 层级自动生成；如果要独特效果，把 `kind` 设为 `unique` 并在分支上给 `modifier`。

### 加一条事件

在 `src/content/data/events/*.yaml` 追加：

```yaml
- id: MING_e_1640_99
  title: 某事件
  desc: 某描述
  scope: country
  country: MING
  trigger:
    date: { after: 1640-01-01, before: 1641-12-31 }
  mtth: 180
  fire_once: true
  options:
    - id: a
      name: 选项 A
      effect: [{ add_stability: -2 }, { add_treasury: -10000 }]
    - id: b
      name: 选项 B
      effect: [{ add_estate_loyalty: { estate: peasants, value: 3 } }]
```

`pnpm validate` 会校验 trigger / effect 键白名单、日期、引用。

### 加一条税法

在 `src/content/data/tax_laws/*.yaml` 追加，`estate` 必须是已启用阶级，`rate ≤ 0.30`，`efficiency 0–1`，`evasion_base ≤ 0.50`。势力专属加 `country: TAG`。

### 加一个势力

1. `countries.yaml` 加国家。
2. `estates/countries.yaml` 加 4–8 个阶级，`income_share` 之和 = 1。
3. `focus_packs.yaml` 加 6 条分支 × 7 层。
4. 事件 / 剧本里加开局省份与军队。
5. `pnpm validate`。

## 7. 已知限制（v1）

- 地图是**程序化生成**的东亚形状，不是真实历史边界；边疆省份较大，下属省名用“东 / 西”后缀。
- 国策描述对部分条目使用“分支主题 + 条目名”生成；可逐条替换为独立文案。
- 事件总量 75 条（12 条链 + 共享池 + 8 条新增史实事件），未达到设计目标的 ~300；框架与校验已就绪，继续加 YAML 即可。
- 税法 42 条、将领 73 名，未达到 ~70 / ~140 的目标。
- 战斗是省级逐日抽象，没有战术地图、海军战斗、战争迷雾。
- 饥荒 / 瘟疫目前通过事件与粮食短缺影响人口 / 稳定，没有独立传播模型。
- `hasAdvisor` 触发条件暂未实现（没有顾问系统）。
- 存档 version 6；可读取 v1–v5 存档，并自动补齐行军、海运、训练、停战、藩属与战争伤亡字段。
- AI 是“合理施压”级别，不追求最优；70 年模拟可能走向大顺、清或地方藩属主导的非历史结局。

## 8. 设计取舍

- **结构压力优先**：大明默认税法下是赤字；什么都不做会滑向欠饷 → 民变 → 失省。
- **阶级即政治**：税法作用于阶级，不作用于抽象“国家”；加税一定有人受损。
- **历史是概率**：甲申、入关、取台、丙子、锁国、雅克萨都有窗口与前置，但不必然发生。
- **可读的失败**：欠饷、抗税、民变、失城都在顶栏、财政面板、阶级面板、事件日志留痕。

- **国策/科研取消**：进行中的国策或研究可随时取消，进度清零；完成后会弹出“国策告成/新学告成”事件，并在事件处理完后恢复原游戏速度。
