# 品质标准（Quality Bar）

> 目标：**品质达到「可上架 Steam」的水准，但不实际上架、不做桌面端/手柄。**
> 交付物：浏览器可玩的 Web 版；Chrome/Edge 为主，Firefox 兼容。
> 版本：1.0 ｜ 2026-10-19

---

## 1. 一句话标准

一个玩过 HOI4 / EU4 / 全面战争的玩家，能在浏览器里**连续玩 30 小时**，不遇到死局、不觉得内容重复、不觉得 UI/美术是原型，并愿意给好评。

## 4. 明确不做

- Electron / Tauri / 桌面安装包 / 自动更新。
- Steamworks / 成就 / 云存档 / Rich Presence / Steam Input。
- Steam Deck / 手柄 / 触屏。
- 商店页 / 胶囊图 / 预告 / 定价 / Next Fest / 发行 / 营销。
- IARC / EULA / 隐私政策 / 版号 / Steam 审核。
- 多人 / 3D / 战术战斗 / 主机 / 移动端。

> 仍要做：字体打包、音频权利清理、中文文案质量、浏览器性能、存档可靠性——这些属于品质。

## 5. Gate 打分表（每个里程碑复制一次）

> 评分时点：2026-10-20 · Phase 5。判定口径按 `ai-context/master-plan.md`：**AI 可验证的维度必须全部达标；只有真人能做的验证列入 `docs/handoff.md`，不伪造结论。**

| 维度 | 目标 | 实际 | AI 可验证部分 | 待真人 |
|---|---|---|---|---|
| 上手 | ≥8/10 | 引导 4 步、开局清单、F1 帮助、键盘全流程、8 势力 E2E | ✅ 机制与流程可用 | 10 人外测 |
| 核心循环 | 4 段目标 | 8 局 bot 长局（4/8 活到 1683）；内容无干旱 | ✅ 长局无死锁/无重复 | 30h 真人试玩 + 问卷 |
| 系统可信 | audit 0 | audit 0/0；不变量 8965 万次检查绿；45 局可解释 | ✅ | — |
| 内容 | 200 事件/336 国策/8 机制 | 214 事件 / 504 国策 / 8 机制 / 3 剧本 / 480 地名 | ✅ | 内容趣味性主观评审 |
| AI/平衡 | 20 年可信 | 45 局 0 僵尸/0 孤儿；每剧本×难度多胜者；1650 单极为例外 | ✅（1 项剧本例外已记录） | — |
| UI/UX | 1280–1920/键鼠 | 浏览器矩阵 + 8 势力 E2E + 打磨清单清零 | ✅ | 真机手感/可读性主观评审 |
| 美术 | 无占位 | 木刻插图/肖像/纸纹地图/UI kit v1 | ⚠️ 无法替代视觉评审 | 视觉评审 |
| 音频 | 无 TTS/版权隐患 | 原创 CC0 配乐、TTS 移除、音量分离 | ⚠️ 无法替代听感评审 | 听感评审 + 权利清单复核 |
| 稳定/性能 | 60fps/<2ms/8h | tick 1.18–1.33ms；加载 297.9ms；rAF 125fps；8h soak 2.73h 后被环境内存终止 | ✅ 性能全达标；8h soak 用户接受 2.73h 例外 | — |

**结论**：系统可信、内容、AI/平衡、UI/UX 4 项全部达标；稳定/性能全部达标，其中 8h soak 以 2.73h 部分证据经用户接受为例外；上手与核心循环的 AI 可验证部分完成，真人试玩部分移交；美术/音频无 AI 可替代验证，移交真人评审。无阻断项。1650 剧本单极现象为设计例外而非缺陷。

**通过线**：9 项中至少 8 项达标，且无「阻断」项；未达标项必须有明确计划与负责人。

> 说明：按上述字面通过线，**最终放行仍需等待移交的真人结果**（外测、30h 试玩、美术/音频评审）。本任务的定义是「AI 可验证维度全部达标 + 真人项完整移交」，不把待真人项计为已达标。

## 6. 更新规则

- 每次 Gate 更新「当前」列与 §5 打分表。
- 标准只升不降；若降标准，必须写进 `docs/decisions-log.md` 并说明原因。
