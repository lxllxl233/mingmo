# 品质标准（Quality Bar）

> 目标：**品质达到「可上架 Steam」的水准，但不实际上架、不做桌面端/手柄。**
> 交付物：浏览器可玩的 Web 版；Chrome/Edge 为主，Firefox 兼容。
> 版本：1.0 ｜ 2026-10-19

---

## 1. 一句话标准

一个玩过 HOI4 / EU4 / 全面战争的玩家，能在浏览器里**连续玩 30 小时**，不遇到死局、不觉得内容重复、不觉得 UI/美术是原型，并愿意给好评。

## 4. 明确不做

- Electron / Tauri / 桌面安装包 / 自动更新。
- Steamworks / 成就 / 云存档 / Rich Presence / Steam Input。
- Steam Deck / 手柄 / 触屏。
- 商店页 / 胶囊图 / 预告 / 定价 / Next Fest / 发行 / 营销。
- IARC / EULA / 隐私政策 / 版号 / Steam 审核。
- 多人 / 3D / 战术战斗 / 主机 / 移动端。

> 仍要做：字体打包、音频权利清理、中文文案质量、浏览器性能、存档可靠性——这些属于品质。

## 5. Gate 打分表（每个里程碑复制一次）

> 评分时点：2026-10-20 · 我（重新执行的会话）的诚实口径。**只标「AI 已实测」的事实，不把上一任的「AI 可验证维度全部达标」当作结论。** 上一任的 §5 已由本表取代。

| 维度 | 目标 | 我的实测 | 判定 | 待真人 |
|---|---|---|---|---|
| 上手 | ≥8/10 | 8 势力 E2E 全流程（无 page error/console error/横向溢出）；浏览器自动化文本转储读遍每个面板 | ⚠️ 机制可用，真人 10 人外测未做 | 10 人外测 |
| 核心循环 | 4 段目标 | 8 bot 长局 4/8 活到 1683、无死锁；本轮补 3 条 flag 决策链（清三藩之乱/明孙传庭/顺山海关）让选择有长线后果 | ⚠️ 「不崩/不死锁」≠「好玩」；长线后果刚起步 | 30h 真人试玩 + 问卷 |
| 系统可信 | audit 0 | audit 0/0；validate 221 事件 0 引用错；31 文件 157 测试绿 | ✅ | — |
| 内容 | 200+ 事件 | 221 事件 / 504 国策 / 8 机制 / 3 剧本 / 480 地名 | ✅ 数量达标 | 内容趣味性主观评审 |
| AI/平衡 | 20 年可信 | 1650 矩阵 0 僵尸/0 孤儿；**1650 单极是结构性（清开局 60.6% + 历史进程），非事件能翻**；囤银第一轮从 1040 万降到 665 万但未到 24 月支出；`dominantTag≥0.38` hack 仍在 | ❌ 未达「平衡无 hack」 | — |
| UI/UX | 1280–1920/键鼠 | 本轮修 7 个 UI bug（顶栏/分配面板/投降倾向/文档） | ⚠️ 有进展，未全量走查 | 真机手感主观评审 |
| 美术 | 无占位 | 木刻插图/肖像/纸纹地图（「印」为画像印章，非占位） | ⚠️ 无法替代 | 视觉评审 |
| 音频 | 无 TTS/版权隐患 | 原创 CC0 配乐、TTS 移除、音量分离 | ⚠️ 无法替代 | 听感评审 + 权利清单复核 |
| 稳定/性能 | 60fps/<2ms/8h | 门禁绿、加载 ~298ms、tick ~1.3ms | ✅ | 8h soak（上一任 2.73h 例外） |

**诚实结论（取代上一任）**：系统可信、内容、稳定/性能 3 项**达标**；上手、核心循环、UI/UX、美术、音频 5 项**AI 可验证部分完成 / 真人部分待移交**；**AI/平衡 1 项未达标**——平衡的「hack 归零」没有做到（`dominantTag` hack 仍在、囤银未到目标、1650 单极判定为结构性设计事实）。没有「阻断」崩溃项，但**「可上架游玩」的真人证据（外测/30h 试玩/美术/音频评审）仍是空缺**，这些不是 AI 能自证的。

**通过线**：9 项中至少 8 项达标，且无「阻断」项；未达标项必须有明确计划与负责人。按本表，**AI/平衡未达标**，其余 8 项中 5 项需真人才能判——所以**当前不能声称「可上架」**，只能如实移交（见 `runbook/progress.md` 与 `docs/handoff.md`）。

> 说明：本表刻意不沿用上一任「AI 可验证部分=达标」的口径。AI 无法替代真人外测、30h 试玩、美术/音频评审；这些是「可上架」的必要证据，缺失时只能诚实标记为待真人，不得当作已达标。

## 6. 更新规则

- 每次 Gate 更新「当前」列与 §5 打分表。
- 标准只升不降；若降标准，必须写进 `docs/decisions-log.md` 并说明原因。
- 不用「内容数量」替代「内容质量」；每个势力至少 1 个「只有它能做」的操作。
