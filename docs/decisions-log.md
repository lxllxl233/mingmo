## Q1 · 范围：8 个可玩势力 + 4 个 AI 势力

- **状态**：已确认（2026-10-19，用户回复「按 Q-B 开始」语义）
- **决策**：可玩：明、清、顺、南明、郑、蒙古、朝鲜、日本；AI-only：西、和硕特·西藏、荷兰东印度、沙俄。
- **理由**：8 个势力能覆盖「明—清—顺—南明—郑—蒙古—朝鲜—日本」的主要视角；12 个会摊薄机制与内容质量。AI-only 保留地图/事件/外交存在感。
- **后果**：Q4 做 8 个独特机制；Q7 可选补 4 个到 12。国策 336、事件 200–220。
- **推翻条件**：用户明确要求 Q-A（6）或 Q-C（12）。

## Q2 · 美术：木刻/水墨，先规格后外包

- **状态**：默认执行（2026-10-19）
- **决策**：统一「木刻版画 + 水墨 + 朱砂」方向；先做 art bible + 8–12 领袖 + UI kit + 地图纹理；事件插图用版画纹理 + 排版过渡。
- **理由**：当前程序化色块 + Q 版头像与历史大战略的调性冲突；统一风格比逐张精修更能提升「商业感」。
- **后果**：Q5 需要美术外包；预算未定，先用占位/程序化，不阻塞代码。
- **待定**：预算、画师、是否接受 AI 辅助（需披露）。

## Q3 · 音频：移除 Edge TTS，音乐后续原创/买断

- **状态**：默认执行（2026-10-19）
- **决策**：最终品质版不使用 Edge TTS 生成的 11 条语音；先用「无语音 + 字幕/音效」占位；Q5 再决定真人短语音或保持无语音。音乐先用现有 CC BY 过渡，Q5 替换为原创/买断，至少完成署名。
- **理由**：Edge TTS 音色与授权都不适合作为最终品质；机器人语音会直接拉低听感。
- **后果**：`sound.ts` 的语音播放改为可配置；`gen-voices.py` 标记为 legacy；`CREDITS.md` 保留。
- **待定**：是否请配音演员（20–30 句）。

## Q4 · 语言：中文优先，英文 Q7 可选

- **状态**：默认执行（2026-10-19）
- **决策**：品质版先做中文；i18n 架构在 Q3 预留（日志 key、错误码、内容 sidecar），英文翻译放 Q7，不阻塞 Q6 品质验收。

## Q6 · 平衡验收口径：≥50% 规则与 1650 剧本例外

- **状态**：已确认（2026-10-20，Phase 3/5 验收）
- **背景**：1627 开局明 310/480（64.6%）、1650 开局清 291/480（60.6%），「无势力 ≥50% 连续 2 年」在开局即被触发，按字面无法满足。Phase 4 晚期内容加入后，1650 easy/normal 的 20 年终局仍由清单极。
- **决策**：
  1. ≥50% 规则按「相对开局是否继续膨胀 + 20 年终局是否单极」解释；1627 明随崩溃解体，终局无人 ≥50%。
  2. 1650 定位为「残局」剧本，开局即 60.6% 的清在 easy/normal 保持领先属设计例外；hard 存在郑作为替代领先者。
  3. 未达标格数 2（1650 easy/normal），符合 Phase 3「未达标项 ≤2」的验收上限。
- **后果**：最终报告与 qa-checklist 均标注该例外；不为此继续调参（平衡迭代已达上限，且会破坏已锁定矩阵基线）。
- **推翻条件**：若用户要求 1650 easy/normal 必须多胜者，需要重新设计该剧本开局（降低清初始省份或强化反清联盟），属内容设计变更。

## Q6 · 8h soak 验收例外：接受 2.73h 部分证据

- **状态**：用户决定（2026-10-20）
- **背景**：最终树 8h/32x 看海 soak 运行 2.73h（9813s、327 次采样）后，被 Claude Code 环境以「系统内存不足」强制终止（连同静态服务器）；非程序崩溃。期间游戏推进到 1683-12-31 终局，heap 39–128MB（末次 39MB），采样输出无错误行；因进程被终止，未生成脚本最终的 `errors=` 汇总。
- **决策**：接受该 2.73h 部分证据作为 8h soak 的验收例外，不再重跑。理由：无崩溃、无内存持续增长、已跑到终局；环境内存限制不可控，且重启长任务仍可能被再次终止。
- **后果**：`quality-bar.md`、`qa-checklist.md`、`final-report.md` 均标注该例外；不宣称「8h 完整通过」，也不宣称「0 console error」。
- **推翻条件**：发布前如需要完整 8h 证据，可托管 `dist` 后重跑 `SOAK_MINUTES=480 SOAK_SPEED=32x node scripts/soak-ui.mjs`，完成后更新报告。
