# 30 小时试玩记录模板

目标：验证「一个玩过 HOI4/EU4/全战」的玩家能否连续玩 30 小时，不遇到死局、不觉得内容重复、愿意给好评。

## 试玩设置

- 浏览器：Chrome / Edge / Firefox（记录版本）
- 分辨率：1280×800 / 1440×900 / 1920×1080
- 剧本：1627（长局）、1644（易代）、1650（残局）
- 势力：至少 2 个不同机制（如明 + 清，或南明 + 郑）
- 难度：普通；第二轮可困难
- 记录：每 30 分钟截图一次，关键时刻存档

## 时间节点

| 时间 | 检查 |
|---|---|
| 0–15 分钟 | 是否知道我是谁/目标/第一步；是否完成一次分配或国策 |
| 30 分钟 | 是否理解财政/粮食/欠饷/稳定；是否遇到第一个有意义的选择 |
| 3 小时 | 是否有中期目标；是否出现“只能点下一日”的空转 |
| 10 小时 | 是否出现死局/必然输；AI 是否仍可解释；是否觉得事件重复 |
| 30 小时 | 是否完成一个完整战役；是否愿意再开一局；是否遇到崩溃/丢档 |

## 死局判定

- 连续 5 游戏年没有任何可执行的有意义操作；
- 军队全灭且无法重建；
- 国库/粮食长期为 0 且无外交/内政解法；
- 事件弹窗循环/无法关闭；
- 存档无法读取。
