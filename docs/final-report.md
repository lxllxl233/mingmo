## 2. 方法学声明

1. 所有平衡/性能数字来自当前树的可复现脚本，原始输出在 `out/`（gitignored），结论固化在 `docs/qa-checklist.md`。
2. 「30 小时真人通关」以**规则驱动 bot 长局**替代：8 个可玩势力各跑 1627→1683 或死亡。bot 能证明无死锁、无 NaN、内容可消费，**不等同真人体验**；核心循环的真人验证在移交清单。
3. 性能测量在 Windows 11 + Node 20 上完成。Windows 会对持续占用 CPU 的后台进程启用 EcoQoS 节流（实测同一纯 JS 循环 188ms → 1514ms）；所有探针显式 `setPriority(HIGH)`，否则 20 年 tick 会被误测为 4.4ms。
4. 平衡矩阵为无头看海（`createInitialState(..., spectator=true)`），玩家不介入；难度只影响 AI  aggressiveness/资源修正，不改变规则。
5. 「无势力 ≥50% 连续 2 年」的口径：1627/1650 开局即有明 64.6% / 清 60.6%，该条按「相对开局是否继续膨胀、20 年终局是否单极」解释；战争时长探针同时记录逐月最大占比。

## 7. 8 小时 Soak 结果（未完成，待重跑）

- 对象：最终树构建 `out/soak-final`（与当前 `dist` 逐字节一致，已用 `cmp` 校验）。
- 配置：32x 看海，每 30 秒采样日期/heap；console/page error 在脚本结束时汇总。
- 实际运行：**2.73 小时（9813 秒，327 次采样）**，游戏推进至 1627 → **1683-12-31**（终局），随后保持运行。
- 内存：heap 39–128MB，末次采样 39MB；无持续上升趋势。
- 错误：采样输出无错误行；但进程被外部终止，未生成脚本最终的 `errors=` 汇总，**不能宣称 0 error**。
- 终止原因：Claude Code 后台任务监管检测到系统内存不足，强制停止了 soak 与其静态服务器（非程序崩溃；任务通知明确说明不是失败）。
- 结论：**8h 稳定性验收未完成**。已获得的 2.73h 证据支持「无崩溃、无内存持续增长、可跑到终局」，但不足以替代 8h 验收。需用户批准后重跑（环境已限制自动重启）。
